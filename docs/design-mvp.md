# 电商系统第一阶段 MVP 设计说明

## 目标

第一阶段只完成基础购物闭环，确保工程可运行、前后端可独立启动，并为后续业务模块预留清晰边界。

## MVP 范围

- 用户登录
- 商品列表与商品详情
- 购物车
- 地址管理
- 确认订单
- 提交订单
- 模拟支付
- 订单列表与订单详情
- 后台商品管理
- 后台订单管理
- 后台工作台基础看板

## 暂不实现

- 优惠券、积分、PLUS 会员
- 售后、退款、财务对账、分账
- 精细权限、操作日志、导出
- 自动化测试平台、质量大屏

## 页面清单

用户端：

- 登录页
- 首页
- 分类页
- 搜索页
- 商品详情页
- 购物车页
- 确认订单页
- 地址管理页
- 支付页
- 支付结果页
- 订单列表页
- 订单详情页

管理后台：

- 后台登录页
- 工作台首页
- 商品列表页
- 新增/编辑商品页
- 运费模板页
- 订单列表页
- 订单详情页/发货页

## 第一批工程骨架

- `backend`: Spring Boot 后端，先提供 `/api/health`
- `frontend-mobile`: Vue 3 用户端，先提供首页
- `frontend-admin`: Vue 3 管理后台，先提供首页
- `docker-compose.yml`: MySQL 8.4
